# 問題集 JSON を作るときの依頼文（Claude の別チャット用）

下の「ここから」〜「ここまで」を、そのままコピーして、Claude のチャットに貼ります。そのあとで、問題集（PDF・テキスト・画像など）を渡してください。

---

## ここから

あなたは、早押しクイズアプリ「QUIZ KNIGHTS」に取り込む問題集のデータを作る担当です。
このあとに渡す問題集（問題文と正解の一覧）を、下の仕様どおりの JSON にしてください。

### 出力

- JSON だけを出力します（前置き・解説・コードブロック以外の文章は付けません。コードブロックに入れるのはかまいません）。
- 問題が多いときは、50問ずつに分けて出力します。1つ出力したら「続きを出力してよいですか」と聞き、私が「続けて」と言ったら次の50問を出力します。分けても、形式は毎回同じ（最上位の `version`・`title`・`questions` を持つ JSON）にし、`no` は問題集の通し番号のままにします。

### 形式

```json
{
  "version": 1,
  "title": "問題集の名前",
  "questions": [
    {
      "no": 1,
      "q": "日本で/一番高い/山は/何でしょう？",
      "a": "富士山",
      "alt": ["ふじさん", "富士"],
      "wrong": ["北岳", "穂高岳", "立山"]
    }
  ]
}
```

| 項目 | 内容 |
|---|---|
| `no` | 問題番号。問題集にある番号をそのまま使う（なければ 1 から順に） |
| `q` | 問題文。**区切り（`/`）と確定ポイント（`｜`）の印を、問題文の中に直接書く**（下の規則を参照） |
| `a` | 正解。1つだけ。「（）」の中の読みや補足、『』「」は含めない |
| `alt` | 正解として認める別の書き方。読み仮名（ひらがな）、別表記、略称、「さん」などの敬称あり・なし、カタカナ・英語の表記ゆれ。なければ `[]` |
| `wrong` | 誤答の候補を3つ。正解と同じ種類（人名なら人名、地名なら地名）で、もっともらしい間違い。正解と同じ・紛らわしい別表記は入れない |

`cuts`・`sure` という項目は書かないでください（`q` の印から、アプリが自動で作ります）。

### `q` の印の規則

1. **問題文は一字も変えません。** 漢字・かな・記号・「（）」の中の読み仮名も、そのまま写します。事実の誤りに気づいても、直さずに、別に知らせてください。
2. **区切り `/`**: 進行役が読み上げるときの、息継ぎの位置です。文節の切れ目に入れます。
   - 1つの塊は、6〜14文字くらい。読点（、）のあとは必ず切ってよい。
   - 「（）」の中（読み仮名）や、固有名詞・熟語の途中では切らない。読み仮名は、直前の語と同じ塊に入れる。
   - 先頭・末尾・連続した位置には入れない。
3. **確定ポイント `｜`**（全角の縦棒を、1問に1つだけ）: 「ここまで読まれたら、詳しい人なら答えが1つに絞れる」最も早い位置です。
   - 必ず、区切り `/` の直前（塊の終わり）か、問題文の最後に置く（`/` の直前なら `…｜/…` と書く）。
   - 絞れる位置は、**答えを知っている人の目線**で判断します。冒頭のヒントだけで絞れるなら早く、最後の「〜は何でしょう」まで読まないと絞れないなら、問いかけの直前に置く。
   - 「〜は何でしょう？」の問いかけの部分は、確定ポイントより後ろに置く。
   - 迷ったら、遅めに置く（早すぎると、CPUが早く押してしまいます）。
4. 問題文の中に、もともと「/」や「｜」が含まれる場合は、別の文字に直さず、そのことを知らせてください。

### 例

入力:

> 3. 銀行が預金の受け入れと貸し出しを繰り返すことで、当初の預金の何倍もの預金通貨を生み出す仕組みを何というでしょう？　答え: 信用創造

出力:

```json
{ "no": 3, "q": "銀行が預金の受け入れと/貸し出しを繰り返す/ことで、当初の預金の/何倍もの預金通貨を｜/生み出す仕組みを/何というでしょう？", "a": "信用創造", "alt": ["しんようそうぞう"], "wrong": ["預金乗数", "金融仲介", "信用収縮"] }
```

### 出力の前に確認すること

- `q` から `/` と `｜` を取り除くと、元の問題文と完全に一致する。
- `｜` が1問に1つだけあり、問題文の先頭ではない。
- `a` に「（）」や『』が残っていない。
- `wrong` が3つで、`a` と重複していない。
- JSON として正しい（引用符・カンマ・括弧）。

## 補足（人間向け）

- 出力された JSON は、進行役の画面の「📚 問題集」→「JSONファイルを選ぶ」（またはテキスト欄に貼り付け）で取り込みます。複数回に分けたときは、2回目以降を「末尾に追加」で取り込みます。
- 取り込み時に、形式の検査が走ります（範囲外の位置・空の正解・重複した番号など）。問題があった行は一覧で知らせます。
- 確定ポイントは、問題集の画面で1問ずつ直せます。
- 問題集は、進行役のブラウザにだけ保存されます。市販・配布されている問題集から作った JSON は、公開リポジトリに入れないでください。
