# QUIZ KNIGHTS（クイズ騎士団）

**早押しクイズが、みんなで挑むRPGバトルになる。**
https://quiz-knights.quiz-knights.workers.dev

## ひとことで

クイズの「早押し」と、職業・魔王・アイテムの「RPGバトル」を合わせた、オンラインのパーティーゲームです。
問題の読み上げと正誤の判定は、進行役（人間）が担当。早押しで勝って正解した人が、自分の職業の技で戦います。
ブラウザだけで遊べて、スマホにも対応。無料で公開しています。

## 短い紹介文（SNS向け）

> 早押しクイズ × RPGバトル「QUIZ KNIGHTS」を作りました。早押しに勝って正解すれば、攻撃・回復・アイテムで魔王に挑めます。職業25種・魔王6体・アイテム30種。ブラウザだけで、スマホでも遊べます。

## 遊び方

1. 進行役が部屋を作り、参加者がURLから入室します。
2. 進行役がクイズを読み上げ、参加者は「押す！」ボタンで早押し。いちばん早かった人が回答します。
3. 正解したら、通常攻撃・職業の能力・アイテムから選んで行動。誤答は、答えた本人だけが2ダメージ。
4. 1問ごとにCPU（魔王など）が動きます。魔王を倒せば勝ち。1試合は約20問です。

## 特徴

- **職業25種**: 戦士・僧侶・魔法使い・賢者・バトルマスター・道化師・怪盗・道具使い・ばくだんいわ…。クリックすると説明が出ます。
- **魔王6体**: それぞれ3〜4種類の技を持つ強敵。登場や討伐の演出つき。魔王を「参加者が操作する」遊び方もできます。
- **アイテム30種**: 開始時にランダムで配られ、正解したときに使えます。仲間の持ち物は見えて、敵の持ち物は個数だけ。
- **CPU戦とユーザー対戦**: 魔王や職業のCPUと協力して戦う「CPU戦」と、最大3チームで戦う「ユーザー対戦」。
- **遠隔の早押しに強い**: サーバーが時刻をそろえて判定するので、通信の遅れがあっても公平。個人ごとのディレイ設定もできます。
- **途中参加・途中退室OK**。進行役が通信エラーで落ちても、ほかの人が引き継いで、バトルを続きから進められます。
- **スマホ対応**。通話アプリと一緒に遊ぶ前提で、音声機能はありません。
