# セキュリティ（QUIZ KNIGHTS）

認証（ログイン）なしで公開する前提で、**荒らし・負荷・不正な入力・画面への差し込み**を防ぐ作りになっています。身内のクイズ会を想定しているので、「誰でも部屋に入れる」こと自体は仕様です。

## 守りたいもの

| 守るもの | 脅威 |
|---|---|
| サービスが使えること（部屋が作れる・早押しできる） | 大量アクセス（DDoS）、部屋の占領、無料枠の使い切り |
| 参加者の画面 | 名前・チャットなどからの HTML・スクリプトの差し込み（XSS）、文字化けでの偽装 |
| サーバーの動き | 巨大・不正なメッセージ、特別な名前（`__proto__` など）での乗っ取り、連打 |
| 部屋のパスワード・進行役の鍵 | 総当たり |
| 部屋の進行 | 進行役の鍵の漏れ（鍵は、作った人のブラウザだけが持つ） |

## 対策の一覧

### 入口（Worker）
- **別のサイトからの WebSocket を断る。** `Origin` が、このサイトと違えば 403（アプリ以外の道具など、`Origin` が無いものは通す）。他のサイトのページから、来訪者の端末を使って部屋に接続されることを防ぎます。
- **同じ接続元（IP）からの短時間の大量アクセスを、Durable Object に届く前に断る**（接続は10秒に30回、部屋一覧は10秒に60回まで。超えると 429）。Durable Object への問い合わせは、無料枠では1日10万回までなので、無駄に使わせないための措置です。
- **部屋一覧は1秒使い回す。** 一覧の取得が集中しても、Durable Object への問い合わせは、ほとんど増えません。
- 部屋一覧は GET だけ（ほかは 405）。

### 部屋（Durable Object）
- **メッセージの大きさの上限**: 参加者4KB、進行役256KB。超えたら、接続ごと切ります。文字列（JSON）以外は、無視します。
- **メッセージの回数制限**（接続ごと）: 参加者は1秒に20通（瞬間は40通まで）、進行役は1秒に200通。超えた分は捨て、やりすぎる接続は切ります。
- **チャットの連投制限**: 1人あたり、5件まで続けて送れて、あとは2秒に1件。
- **接続数の上限**: 部屋ごとに150本、同じ接続元から30本。
- **参加者数の上限**: 部屋ごとに60人、同じ接続元から20人。
- **部屋の作成の制限**: 同じ接続元が、同時に持てる部屋は3つ、1時間に作れるのは6回まで。16個の部屋を1人に占領されないための措置です。進行役が不在の部屋は、30分で自動的に閉じます。
- **パスワード・進行役の鍵の総当たり対策**: 同じ接続元から6回失敗すると、1分間は、正しくても受け付けません。比較は、一致した位置で時間が変わらない方式です。
- **入力の掃除**: 名前・ひとこと・チャット・部屋名から、制御文字、文字の向きを変える文字（表示の偽装に使われる）、ゼロ幅文字を除き、空白を整え、長さを切ります。絵文字の途中では切りません。
- **特別な名前の拒否**: 参加者の探索は、自分自身のプロパティだけを見ます（`__proto__`・`constructor` などで、`Object` の中身を取り出されたり、汚染されたりしません）。職業・魔王・戦う相手は、決まった一覧にあるものだけを受け付けます。
- 答えの番号・質問の番号は、整数だけ。CPU の ID は英数字だけに絞り、数は16体まで。

### 画面（ブラウザ）
- **HTML を差し込む場所が、`icon()`（決まったアイコンだけ）に限られる。** 名前・チャットなどは、すべて文字として表示します（Svelte が自動でエスケープ）。`innerHTML`・`eval` などは使っていません（テストで確認）。
- **CSP（Content-Security-Policy）**: スクリプトは自サイトのものだけ（inline・外部なし）。フォントは Google Fonts だけ。`frame-ancestors 'none'` と `X-Frame-Options: DENY` で、他のサイトの中に埋め込めません（クリックジャッキング対策）。
- そのほか: `X-Content-Type-Options: nosniff`、`Referrer-Policy`、`Permissions-Policy`（カメラ・マイクなどを使わない）、`Strict-Transport-Security`、`Cross-Origin-Opener-Policy`。
- 問題集は、進行役のブラウザにだけ保存され、サーバーにも参加者にも送りません。

### 開発・公開
- 秘密の鍵（Cloudflare の API トークン）は、GitHub の Secrets にだけあり、ソースに入っていません（テストで検査）。
- 自動デプロイは、テストが通ったときだけ行います。

## 残っている弱点（意図的に許容しているもの）

- **認証がない。** 部屋に入る人を識別しません。名前は自己申告で、同じ名前の人もいられます。パスワード付きの部屋にすれば、知らない人は入れません。
- **進行役の端末を信頼する作り。** 進行役は、ゲームの計算をするので、進行役が改ざんすれば、結果は変えられます。進行役になれるのは、部屋を作った人と、進行役が不在のときに引き継いだ参加者です。
- **進行役の鍵が漏れたら、乗っ取られる。** 鍵は、進行役のブラウザの保存領域にあります。共有の端末では、使い終わったら、部屋を閉じてください。
- **大規模な DDoS は、アプリの対策だけでは防げない。** Cloudflare が、ネットワーク層・アプリケーション層の DDoS を自動で防ぎます（無料プランを含む）。それでも足りないときは、下の設定を使ってください。
- 部屋のパスワードは、部屋の保存領域に平文で保存されます（進行役の画面に表示するため）。ほかのサービスと同じパスワードを使わないでください。

## Cloudflare のダッシュボードで足せる対策（コードの外）

アプリの外で、さらに強くしたいときの設定です。いずれも、無料プランで使えます（上限はプランによります）。

1. **Security → Bots → Bot Fight Mode をオン**: 明らかなボットを、自動で止めます。
2. **Security → WAF → Rate limiting rules**: 次のような規則を1つ作ります。
   - 対象: URI パスが `/ws` または `/api/rooms`
   - 同じ IP から、10秒に100リクエストを超えたら、1分間ブロック
3. **Security → Settings → Security Level を「中」以上**にして、攻撃を受けているときだけ「Under Attack Mode」にします。
4. **Workers の使用量（Workers & Pages → quiz-knights → Metrics）** を、たまに確認します。無料枠（Durable Objects は1日10万リクエスト）に近づいていたら、攻撃や、異常なアクセスの可能性があります。

## 確認するには

```bash
npm test
```

- `test/server/safe.test.mjs`: 入力の掃除・比較・回数制限の部品
- `test/server/server.test.mjs`（「防御:」で始まるテスト）: 実際のサーバーを起動して、Origin 検査、サイズ・回数の上限、総当たり、特別な名前、部屋の作成の制限などを確かめます
- `test/client/security.test.mjs`: HTML の差し込み口、CSP などのヘッダー、秘密の鍵の混入
